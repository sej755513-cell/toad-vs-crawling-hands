ERROR — CODE 100

The game failed to initialize. This page watches the embedded game and shows this message if it doesn't create level data.
Try these:
  • Click Retry to reload the game frame and try again.
  • Open browser console (F12) and look for script errors in the embedded frame.
  • Click Force Start to attempt to call the game's start() / resetRun() functions.
If you have a local copy you can test with the console: in the frame's context run start() or resetRun().
